1. REGLAS INVIOLABLES (aplican a TODAS las fases)
--------------------------------------------------------------------------------

R1. CONTENIDO LITERAL. El contenido migrado (títulos, cuerpos, fechas,
    autorías, categorías, enlaces, imágenes, adjuntos) NUNCA se resume,
    reescribe, reinterpreta ni inventa. El rediseño cambia SOLO el contenedor
    visual. No editar content/, inventory/, ni los HTML de content/posts/,
    content/pages/, content/attachments/, content/raw/.

R2. IDENTIDAD. Los colores corporativos son los del logo: rosa, morado, lila
    y negro. PROHIBIDO introducir amarillo, coral, menta o cualquier color
    heredado de la referencia FCAM como color protagonista. Los únicos colores
    permitidos fuera de la paleta corporativa son tonos utilitarios discretos
    para estados funcionales (éxito/error en formularios), que nunca deben
    dominar una sección.

R3. LOGO. El logo oficial se usa tal cual está en assets/images/. No se
    recolorea, no se recorta, no se le agregan efectos.

R4. PLACEHOLDERS. Solo se permiten placeholders para funciones NUEVAS que no
    existen en el portal original (formulario de contacto moderno, ruta de
    solicitud de apoyo, proceso de afiliación, política de privacidad, datos
    institucionales no publicados). Un placeholder debe verse claramente como
    tal (clase .placeholder ya existente). NUNCA usar un placeholder para
    sustituir contenido que sí existe en el sitio original.

R5. SIN FRAMEWORKS. El sitio es HTML + CSS + JavaScript vanilla, sin build
    step, sin npm, sin dependencias externas salvo Google Fonts. Debe abrir
    con un servidor estático simple (python3 -m http.server).

R6. ACCESIBILIDAD. Mantener y mejorar: skip-link, aria-labels, navegación por
    teclado, foco visible, contraste AA mínimo en todo texto. Toda animación
    debe respetar @media (prefers-reduced-motion: reduce).

R7. RESPONSIVE. Todo componente nuevo debe funcionar en 360px, 620px, 900px y
    1180px+ de ancho. Sin scroll horizontal en ningún breakpoint.

R8. VERIFICACIÓN POR FASE. Al terminar cada fase: levantar servidor local,
    navegar la portada y al menos 3 rutas internas (#/recursos, #/actualidad,
    una ficha de contenido), revisar consola sin errores y validar los
    criterios de cierre de la fase. No avanzar con errores abiertos.

2. SISTEMA DE DISEÑO (fuente de verdad para todas las fases)
--------------------------------------------------------------------------------

2.1 CONCEPTO RECTOR — «La sombrilla que organiza»

El sistema gráfico deriva del logo:
a) ARCOS DE SOMBRILLA: semicírculos concéntricos (sólidos, punteados y en
   línea fina) como motivo decorativo en héroe, tarjetas y separadores.
   Se dibujan con SVG inline o border-radius/clip-path en CSS. Siempre en
   morado o lila, con opacidades entre .15 y .55.
b) SILUETAS EN MOVIMIENTO: el dinamismo del logo se traduce en
   micro-animaciones de entrada (fade + translateY) y patrones sutiles.
   No dibujar figuras humanas nuevas; el movimiento es de la interfaz.

2.2 PALETA (variables CSS obligatorias en :root)

  --ink:         #1a1118;   /* negro tinta: texto, bordes, footer, topbar */
  --paper:       #fdf8f6;   /* lienzo general, blanco cálido */
  --rosa:        #f8e3e7;   /* fondo héroe y secciones tintadas */
  --rosa-suave:  #fbeef0;   /* tinte alternativo de sección */
  --morado:      #6d3fa4;   /* primario: botones, enlaces, categorías */
  --morado-osc:  #472668;   /* bandas oscuras, eyebrows, profundidad */
  --lila:        #b99bdd;   /* acento: arcos, hovers, fondos de tarjeta */
  --lila-claro:  #e9def6;   /* fondo de tarjeta alternativo */
  --blanco:      #ffffff;
  --linea:       rgba(26,17,24,.14);
  --sombra:      0 18px 45px rgba(71,38,104,.14);

Reglas de uso:
- Máximo 2 colores protagonistas por sección.
- Texto sobre --morado-osc y --ink: blanco puro o lila claro (#d8c8ec para
  texto secundario sobre morado oscuro).
- Texto sobre --rosa, --lila-claro, --paper: --ink o --morado-osc.
- Enlaces y acciones: --morado. Hover: --morado-osc.
- ELIMINAR de styles.css todo rastro de: --coral, --yellow, --mint y sus usos.

2.3 TIPOGRAFÍA

- Display/serif: "Fraunces" (Google Fonts, opsz 9..144, pesos 600/700/800).
  Titulares H1 portada: clamp(3rem, 7vw, 6.5rem), letter-spacing -0.03em,
  line-height 1.04. Palabras clave del titular pueden ir en --morado.
- Sans: "DM Sans" (400/500/700). Cuerpo 1.05–1.15rem, line-height 1.7.
- Eyebrow (firma de sección): mayúsculas, font-size .78rem, font-weight 800,
  letter-spacing .18em, color --morado-osc.
- Cargar fuentes con preconnect + font-display: swap.

2.4 COMPONENTES BASE

- Botón primario: fondo --morado, texto blanco, border-radius 999px,
  min-height 48px, font-weight 800. Hover: --morado-osc.
- Botón secundario: transparente, borde 2px --ink, texto --ink.
- Botón sobre fondo oscuro: fondo --lila, texto --ink.
- Tarjeta: fondo blanco, borde 0.5-1px --linea, border-radius 12px,
  sombra suave solo en hover (translateY(-3px) + --sombra).
- Píldora de filtro: border-radius 999px; activa = fondo --ink texto blanco;
  inactiva = borde 1px, texto atenuado.
- Fotografías del archivo: filter grayscale(1) + mix-blend-mode multiply
  sobre fondos --morado o --lila (duotono). Las portadas de PDFs y documentos
  históricos se muestran SIN alterar dentro de marcos neutros.

2.5 MOVIMIENTO

- Entrada al hacer scroll: opacity 0→1 + translateY(20px→0), 300ms ease-out,
  implementado con IntersectionObserver y una clase .reveal.
- Contadores de cifras: animar de 0 al valor al entrar en viewport (600ms).
- Hover en tarjetas de ejes: el arco punteado decorativo rota lentamente
  (transform rotate, transition 2s).
- TODO envuelto en @media (prefers-reduced-motion: reduce) { desactivar }.

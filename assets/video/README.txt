Coloca aquí un archivo llamado hero.mp4 para usarlo como video de fondo del héroe.
Recomendado: H.264/MP4, 1920x1080, 8-15s en bucle, SIN audio, optimizado (< 5 MB idealmente).
Si no existe este archivo, el héroe usa automáticamente el montaje de fotografías del archivo.
El <video> es muted + autoplay + loop + playsinline; se oculta solo si el archivo no carga.
